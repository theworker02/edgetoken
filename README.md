# edgetoken

Edge identifiers and token tokens for idempotent workflows.

**Site:** https://theworker02.github.io/edgetoken/

## Install / run

```bash
git clone https://github.com/theworker02/edgetoken.git
cd edgetoken
node src/cli.js
node --test
```
